El token se guarda solo en este navegador (localStorage). Nunca se envía a ningún servidor externo — solo a la API oficial de GitHub.

  1. Andá a github.com/settings/tokens/new
  2. Nombre: gestor-horariocentro
  3. Expiración: la que quieras (90 días recomendado)
  4. Permiso: tildá solo repo
  5. Copiá el token generado y pegálo abajo
